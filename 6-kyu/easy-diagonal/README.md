<h2><a href=https://www.codewars.com/kata/559b8e46fa060b2c6a0000bf/train/javascript target="_blank">Easy Diagonal</a></h2><h3>6 kyu</h3><p>In the drawing below we have a part of the Pascal's triangle, lines are numbered from <strong>zero</strong> (top).The left diagonal in pale blue with only numbers equal to 1 is diagonal <strong>zero</strong>, then in dark green (1, 2, 3, 4, 5, 6, 7) is diagonal 1, then in pale green (1, 3, 6, 10, 15, 21) isdiagonal 2 and so on.</p><p><img alt="alternative text" src="http://i.imgur.com/eUGaNvIm.jpg"></p><p>We want to calculate the sum of the binomial coefficients on a given diagonal.The sum on diagonal 0 is 8 (we'll write it S(7, 0), 7 is the number of the line where we start, 0 is the number of the diagonal). In the same way S(7, 1) is 28, S(7, 2) is 56.</p><p>Can you write a program which calculates S(n, p) where n is the line where we start and p is the number of the diagonal?</p><p>The function will take n and p (with always: n ≥ p ≥ 0) as parameters and will return the sum.</p><h4 id="examples">Examples:</h4><pre><code>diagonal(20, 3) =&gt; 5985diagonal(20, 4) =&gt; 20349</code></pre><h4 id="hint">Hint:</h4><p>When following a diagonal from top to bottom have a look at the numbers on the diagonal at its right.</p><h4 id="ref">Ref:</h4><p><a href="http://mathworld.wolfram.com/BinomialCoefficient.html" data-turbolinks="false" target="_blank">http://mathworld.wolfram.com/BinomialCoefficient.html</a></p>

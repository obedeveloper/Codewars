<h2><a href=https://www.codewars.com/kata/6a2c4aa28dfc3df3a3dc58ec/train/javascript target="_blank">PromiseLike I: State and Basic Then</a></h2><h3>6 kyu</h3><h1 id="promiselike-i-state-and-basic-then">PromiseLike I: State and Basic Then</h1><p>Implement a small educational <code>MyPromise</code> class.</p><p>This is not a full Promise/A+ implementation yet. In this kata, focus only on the first pieces:</p><ul><li>a promise starts in the <code>pending</code> state</li><li><code>resolve(value)</code> moves it to <code>fulfilled</code></li><li><code>reject(reason)</code> moves it to <code>rejected</code></li><li>once settled, the state cannot change again</li><li><code>then(onFulfilled, onRejected)</code> registers handlers</li><li>handlers registered before an async settlement should run when the promise settles</li><li>handlers registered after settlement should still receive the stored value or reason</li><li>if the executor throws, the promise should reject with that error</li></ul><p>Examples:</p><pre><code class="language-js">const fulfilled = new MyPromise((resolve) =&gt; {  resolve(42);});fulfilled.then(value =&gt; {  console.log(value); // 42});</code></pre><pre><code class="language-js">const rejected = new MyPromise((resolve, reject) =&gt; {  reject("fail");});rejected.then(null, reason =&gt; {  console.log(reason); // "fail"});</code></pre><p>Handlers may be registered before an asynchronous settlement:</p><pre><code class="language-js">const promise = new MyPromise((resolve) =&gt; {  setTimeout(() =&gt; resolve("later"), 10);});promise.then(value =&gt; {  console.log(value); // "later"});</code></pre><p>Only the first settlement should count:</p><pre><code class="language-js">const promise = new MyPromise((resolve, reject) =&gt; {  resolve(1);  reject(2);  resolve(3);});promise.then(value =&gt; {  console.log(value); // 1});</code></pre><p>For this kata, <code>then</code> does not need to return a new promise. Chaining comes later.</p><p>This kata exposes the inner state machine behind promises before adding the more advanced behavior.</p>
